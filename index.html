探索性因子分析（EFA）、验证性因素分析（CFA）、测验的项目分析、项目反应理论（IRT）——用人话，从零讲起。每讲配专有名词速查表和「什么时候用得上」，最后有作业真实 SPSS 数据页与作业反馈汇总页。

0. 开场白：算得出信度，挖得出结构

你编好了一份量表，或者拿到一份现成的量表数据。摆在面前的永远是两个问题：这套题「可信吗」——分数稳不稳、题目是不是在齐心协力测同一个东西；这套题「到底测到了什么」——分数背后藏着几个特质。上一讲我们已经把「效度」的概念讲清楚了，但留了一个尾巴：结构效度说起来是「分数结构符合理论」，它到底怎么用数据算出来？

这一讲就补上这个尾巴。前半场在 SPSS 里把信度算出来：多级计分用克隆巴赫 α，答对答错 0/1 计分用库理信度，多层量表和成套测验的总分用分层 α 系数。后半场进入正题——探索性因子分析（EFA）：一种数据驱动的统计技术，让「题目之间有多像」自己说出背后有几个维度，再用大五人格的真实数据走完五步流程。

路线一句话：先把信度算到手（α、K-R、分层 α）→ 给效度攒三类证据（内容、结构、效标）→ 搞懂 EFA 的方差分解原理和三个核心概念 → 五步跑出因子结构并学会读斜交旋转的输出。

2. 什么时候用得上这一讲

  • 如果你手头有一份多题量表的一次施测数据（如 11 个分测验、175 人）→ 用克隆巴赫 α → 得到内部一致性信度和「该删哪道题」的线索。
  • 如果你手头的测验按答对/答错 0/1 计分 → 用库理信度 K-R20/K-R21 → 得到这份 0/1 测验的信度。
  • 如果你手头是一套多层试卷或几个分测验要报总分 → 用分层 α / 合成分数信度公式 → 得到总分这个数的信度。
  • 如果你想检查一份试卷题目内容是否覆盖考纲 → 用双向细目表 → 得到内容效度证据。
  • 如果你有一大堆题目、不知道背后有几个维度 → 用 EFA 五步流程 → 得到因子个数、每题归属和因子命名。

3.1 信度体系与克隆巴赫 α：把「可信」算出来

什么时候用得上：你拿到一份多题量表的一次施测数据，想知道这套题内部是否互相一致，也就是同质性信度。信度家族其实有四兄弟：重测信度（隔段时间测两次看相关）、复本信度（两套等值卷看相关）、分半信度（一套题对半分看相关）、同质性信度（看各题是否齐心）。前三种都要施测两次或者拆卷，而克隆巴赫 α 只要一次施测就能算，所以日常检验量表最常用它。它产出两个决定：这套题能不能用、哪道题在拖后腿。

直觉：把量表想成一个合唱团。如果每个人唱的是同一首旋律，总音量就稳，谁缺席都不太影响整体——这就是「同质」，信度高。要是有人唱的是另一首歌，总效果就随机波动大，今天听一个样明天听一个样。α 回答的问题就是：这 k 道题，是不是在合唱同一首歌？

术语与公式：克隆巴赫 α（Cronbach's α）刻画量表的内部一致性信度。它的标准化形式只依赖两个量：

α = k·r̄ / ( 1 + (k−1)·r̄ )

公式里 k 是量表题目数；r̄ 是题目两两之间相关的平均值。题目越多、题间相关越高，α 就越大——这两条就是这个公式的全部含义。SPSS 里的操作路径：Analyze → Scale → Reliability Analysis，把题目移入 Items 框，Model 选 Alpha；在 Statistics 对话框勾选 Scale if item deleted，才能拿到删题诊断表。课件例子用 wiscsem.sav（n=175，11 个分测验），输出 Reliability Statistics 表给出 Cronbach's Alpha = .791，标准化后的 α 为 .790，题数 11。配套的 Item-Total Statistics 表里有一列「Cronbach's Alpha if Item Deleted」：某题这一格的数字比总 α 还大，说明删掉它 α 反而会升高。本例 10 个分测验删掉后 α 都降到 .759~.787，唯独 coding 的校正题总相关只有 .079，删掉它 α 升到 .813——它就是那个跑调的团员。

判读与常见坑：按 0.9/0.8/0.7 三条线判读：α≥0.9 很好；0.8~0.9 良好；0.7~0.8 可接受；<0.7 偏低。课件例子的 .791 落在可接受一档。常见坑一：上一讲作业里个别同学把信效度关系写反——「信度越高效度一般也会越高」是错的，信度只是前提，不是保证。常见坑二：看到 if Item Deleted 更大就立刻删题。先看这道题在理论上该不该留，删完之后 α 要重新算重新报，不能拿旧表充数。

3.2 库理信度 K-R20 / K-R21：0/1 计分专用

什么时候用得上：你的测验是判断题、选择题这类按「答对=1、答错=0」计分的题目，想做信度检验。0/1 变量的方差被难度完全决定，普通的信度公式里有些量是重复的，于是有更直接的专用公式——库理信度（Kuder-Richardson reliability）。它只服务二分计分数据：K-R20 需要每道题的难度，K-R21 只要平均难度。产出决定：这套 0/1 测验可信到什么程度。

直觉：一份判断题卷子，如果会做的人大多数题都对、不会做的人大多数题都错，那每人总分就分得清清楚楚，两次考试名次也稳——这就是高信度。反过来，如果人人都靠猜、每题对错五五开，总分就纯属抽签。库理信度做的事：看「会不会」这个真本事能不能透过 0/1 的对错稳定地冒出来。

术语与公式：课件数据 Kuder-Richardson.xlsx（n=22，6 题）。K-R20 公式为：

rxx(K-R20) = K/(K−1) · ( 1 − Σpiqi / s²X )

rxx(K-R21) = K/(K−1) · ( 1 − K·p̄q̄ / s²X )

公式里 K 是题目总数；pi 是第 i 题的答对比例（难度），qi=1−pi 是答错比例；s²X 是全部被试总分的方差；p̄、q̄ 是用平均难度代入的 p 和 q。K-R20 逐题统计难度，更精确；K-R21 只用平均难度，是 K-R20 的简算近似。与 Cronbach's α 的关系一句话：把 0/1 数据直接去算 α，得到的数就是 K-R20——α 是 K-R20 推广到多级计分后的通用版本。

判读与常见坑：判读线与 α 相同：≥0.9 很好、0.8~0.9 良好、0.7~0.8 可接受、<0.7 偏低。常见坑一：多级计分（如五点量表）不能用 K-R，要回到 α；K-R 只认 0/1。常见坑二：K-R21 假设各题难度差不多，题目难度悬殊时它会把信度估低——报告时要说明用的是 20 还是 21。

3.3 分层 α 与合成分数信度：总分也要讲可信

什么时候用得上：一套试题里混着多种计分方式，或者涉及多个测评维度（比如阅读测验里既有选择题又有作文）。这时候不能拿整卷跑一个普通的 α 就了事，因为不同层内部的信度不一样。分层 α 系数（stratified alpha）和成套测验合成分数信度公式就是干这个的：把总分这个数的信度算清楚。产出决定：这个总分能不能拿去解释和比较。

直觉：三股材质不同的绳子拧成一根粗绳，你想知道整根粗绳结不结实。只测其中一股是不够的——细的那股一拉就断，整根绳的强度就被它拖累。分层 α 的思路：把每一层「不可靠的部分」（方差×(1−该层信度)）分别抠出来加总，再看看它占总分方差的比例。

术语与公式：合成分数（composite score）就是学生 p 在 k 个分测验上的加权之和：

Zp = w0 + Σi=1..k wi·Xpi

分层 α 系数（同样形式也用于合成分数信度 ρZZ′，合成分数情形每层还要乘上权重平方 wi²）：

αstrat = 1 − Σ σ²Xi·(1 − ρXi) / σ²X

ρZZ′ = 1 − Σ wi²·σ²Xi·(1 − ρXi) / σ²Z

公式里 σ²Xi 是第 i 层题目所有原始分之和的方差；ρXi（课件写作 ρXiXi′）是第 i 层题目自己的测量信度，比如这层的 Cronbach's α；σ²X（合成分数情形为 σ²Z）是所有题目原始分之和的方差；wi 是第 i 个分测验的权重。哪层方差占比大、信度又低，它对总分信度的拖累就大。

判读与常见坑：算出来的总分信度仍按 0.9 / 0.8、0.7 的线判读。常见坑：把各层 α 求个平均当作总分信度——错，层与层之间方差的相对大小（σ²Xi 占比）才是权重的来源，各层信度的贡献要按方差加权，不能简单平均。

3.4 效度三分类与双向细目表

什么时候用得上：你编了一份新测验，或者要论证一份在用测验「真的测到了想测的东西」。效度证据分三类收集：内容效度看题目覆盖全不全；结构效度看分数背后的结构对不对；效标关联效度看分数能不能预测或对应外部标准。产出决定：这份测验可以用于什么目的、不能用于什么目的。

直觉：像验一辆二手车。翻说明书核对车况描述是否对版——内容效度；拆开看发动机的结构是不是宣传的那种——结构效度；实际开一段看油耗是不是真达到标称——效标关联效度。三条线各自独立取证，都过了才敢说这车（测验）名副其实。

术语与公式：这一节没有公式，有一张关键工具表。内容效度（Content Validity）靠列双向细目表：行为=认知层次、列=学习内容，逐格规定题量。课件几何测验的例子：

结构效度（Construct Validity）有三条取证途径：因子分析（本讲后半场的正题）、相容效度（新测验与测同一特质的旧测验分数的相关要高）、区分效度（与测不同概念的测验的相关要低）。效标关联效度看分数与效标（外部对照标准，如语文考试阅读部分得分）的相关，按取效标的时间分两种：预测效度——现在测验、将来取效标，看预测力；同时效度——效标与测验同时取，看当下对应。上一讲作业里还有同学提出「发展差异验证」：六年级学生阅读平均分应显著高于五年级，这也是结构效度的一种证据。

判读与常见坑：常见坑一：「信度越高效度一般也会越高」——上一讲作业里的真实丢分点，错。信度高只说明分数稳定，测的可能是「稳定地测错」。常见坑二：内容效度靠拍脑袋「我觉得覆盖了」；必须拿双向细目表逐题对照，看每格题量是否符合教学大纲的比例。常见坑三：以为做完因子分析结构效度就齐活了——相容效度、区分效度是并列的证据线，缺一不完整。

3.5 探索性因子分析（EFA）：让数据说出题目背后的结构

什么时候用得上：你手里有一组题目（比如 8 道统计焦虑自评题），不知道它们到底测了几个共同特质。EFA（Exploratory Factor Analysis）用于检验量表的结构效度：考查多个变量之间的相互关系，并用它们共同的潜在特质来解释。产出决定：这些题目背后有几个因子、每道题跟哪个因子亲。不做的话，你只能靠猜来给量表分维度。

直觉：闭上眼听一段合唱，你能猜出背后有几个声部吗？靠的就是不同歌手声音的「相似性」——一起起伏的应该归同一个声部。EFA 干的是同一件事：看题目之间的相关，一起波动的题归为一组，每组背后放一个看不见的「声部」——因子（factor）。

术语与公式：课件的定义原话：一种用来探讨变量潜在结构的统计分析技术。看一组 8 道题（1-非常不同意，5-非常同意）：Item1 一想到今天有心理统计课我就想哭；Item2 同学们嘲笑我不会用SPSS；Item3 理解自由度的概念对我就是小菜一碟；Item4 梦见皮尔逊用相关系数来恐吓我；Item5 抽样分布对我来讲太难懂了；Item6 我几乎没有分析数据方面的经验；Item7 SPSS操作总是和我过意不去；Item8 我从来都不擅长与数字有关的学科。要回答的问题是：这些题是不是在测一个共同的「统计焦虑」特质？注意 EFA 的两个工作方式：同时考虑所有变量以及变量之间的相互关系；基于变量之间的相关来探索潜在结构——所以它是数据驱动的方法。与它相对的 CFA（Confirmatory Factor Analysis，验证性因子分析）是理论驱动：研究者先按理论定好结构，再检验数据是否吻合。

判读与常见坑：常见坑一：把 EFA 当成「分组工具」，以为它会自动把题目分好组——不会，每个题目在所有因子上都有载荷，只是大小不同。常见坑二：EFA 探索出来的结构是「这份数据说的」，不等于结构成立；它需要下一步被验证——这正是第六讲 CFA 要干的事。

3.6 方差分解：每道题的波动从哪来

什么时候用得上：想真正看懂 EFA 的输出，得先知道它的原理：把每道题观测分数的变异拆开。凡是你要解释「为什么这题共同度高、那题共同度低」「为什么因子能解释一部分方差」，都要回到这个分解。产出：对「抽取了多少方差、剩下多少」的完整理解。

直觉：期末全班的平均成绩为什么有高有低？可以拆成三份：全班一起复习带来的共同起伏；有人额外请了家教只影响他自己；还有临场猜对题目的纯运气。EFA 眼里的一道题分数也一样：共同因子推动的部分大家同涨同落，剩下的部分各有各的来头。

术语与公式：每个观测变量（项目）的方差可以写成因子加残差的形式：

Xi = ai1·F1 + ai2·F2 + … + aim·Fm + Ui　（i = 1, 2, …, n）

公式里 Xi 是第 i 道题（观测变量）；F1…Fm 是 m 个公因子；aim 是对应的因子系数；Ui 是第 i 题独有的部分。共同方差（Common variance）是一组观测变量（项目）之间共享的差异量——观测变量之间的相关越高，共同方差所占的比例也越大。唯一方差包含特殊方差（Specific variance）和误差方差（Error variance）两部分，两部分无法分离。特殊方差是指与其他题目无关、而与具体特定题目有关的变异（比如那道题碰巧考了某人请过家教的知识点）；误差方差是指与其他题目无关、也与具体特定题目无关的随机变异。所以整体上一道题的方差分三块：

观测变量方差 = 共同方差（抽取的方差）＋ 特殊方差 ＋ 误差方差（后两者合称未抽取的方差）

判读与常见坑：常见坑：既然特殊方差和误差方差无法分离，就不要在报告里声称「本研究的特殊方差是××、误差方差是××」——它们合并在一起叫唯一方差，EFA 只抽取共同方差部分。

演示 2：方差分解堆叠条——题目间相关越高，共同方差越大

拖动滑块改变题目间平均相关。单因子近似下，共同方差占比约等于平均相关；剩下的唯一方差里特殊与误差各画一半——仅为示意，课件的结论是这两部分无法分离。

3.7 因素载荷、共同度与特征值：读懂 EFA 的三个数

什么时候用得上：EFA 跑完，SPSS 吐出一大表数字。要把表读出含义，只需要搞懂三个量：因素载荷、共同度、特征值。它们分别回答「这道题跟这个因子有多亲」「这道题被因子们解释了几成」「这个因子总共解释了多少方差」。产出：判断哪些题留、因子有几个的全部依据。

直觉：把因子想成音响，题目想成喇叭。载荷就是这道喇叭接在该音响上的音量旋钮——旋钮越大，这道题跟着这个因子起舞越紧。共同度是一台喇叭被「所有音响」驱动起来的总比例。特征值是一个音响带动全部喇叭的总功率。

术语与公式：三个定义共用同一个模型式 Xi = ai1F1 + … + aimFm + Ui。因素载荷描述公因素对观测变量（项目）变异的解释程度，可以解释为每个观测变量与抽取的公因素之间的相关；当因素间相互独立时，标准化因素载荷在数值上等于观测变量与因素之间的相关系数。共同度（communality，记作 hi²）是观测变量方差中由公因素解释的比例：

hi² = ai1² + ai2² + … + aim²

共同度取值介于 0-1 之间，值越大表示公因素对这个观测变量变异的解释比例越高。特征值（eigenvalue）是每个公因素对数据变异的解释能力，即该因素所解释的总方差——F1 的特征值 = a11² + a21² + … + an1²（把所有题目在 F1 上的载荷平方加总）。课件的三题例子看一遍就全懂了：

x1 = 0.95·f1 + 0.22·f2 + u1　　x2 = 0.45·f1 + 0.52·f2 + u2　　x3 = 0.15·f1 + 0.92·f2 + u3

因素载荷：因素 f1 对观测变量 x1 的影响是 0.95。抽取的两个因素对 x1 变异的解释（共同度）= 0.95² + 0.22² = 0.9509。因素 f1 的贡献（特征值）= 0.95² + 0.45² + 0.15² = 1.1275。

判读与常见坑：共同度接近 1 说明该题几乎完全被公因子解释；接近 0 说明这道题基本在「单干」。常见坑：共同度是载荷的平方和，不是载荷之和——0.95 和 0.22 直接相加得 1.17，超出了方差上限，一眼假；平方后才对（0.9509）。

3.8 EFA 五步流程：从前提检验到因子命名

什么时候用得上：拿到一份现成的多题量表数据（课件数据 personality.sav：Item 01~Item 44，n=459），想知道它背后有几个维度。五步流程给出完整作业路径：前提检验 → 决定因子数量 → 抽取因子 → 因子旋转 → 因子命名。产出：一份可以写进报告的因子结构。SPSS 菜单位置：Analyze → Dimension Reduction → Factor。

直觉：像淘金五步。先确认这条河里真的有金子（前提检验）；再估计有几条矿脉（决定因子数）；然后开挖（抽取）；挖出来的沙金要筛掉泥沙、让每颗金子各就各位（旋转）；最后给每堆金子贴上标签（命名）。跳过任何一步，挖出来的都可能是烂泥。

Step 0　前提检验：两个检验都是「通行证」。Bartlett 球形检验检验各变量是否各自独立：零假设是相关阵为单位阵，所以需要拒绝零假设才能做因素分析——若不拒绝，说明变量可能各自独立提供信息，不适合做。课件示例输出：KMO 取样适切性量数 .527，巴特利特球形检验近似卡方 19.094、自由度 6、显著性 .004——.004<.05，拒绝零假设，通行。KMO 检验检查变量间的相关性与偏相关性，公式为：

KMO = ΣΣi≠j rij² / ( ΣΣi≠j rij² + ΣΣi≠j αij² )

公式里 rij 是变量 i 与 j 的简单相关系数，αij 是偏相关系数：偏相关越接近 0，KMO 越接近 1。KMO 统计量越接近于 1，变量间相关性越强、偏相关性越弱，因子分析效果越好。取值在 0~1 之间：课件文字线是 0.7 以上效果比较好、0.5 以下不适合做因子分析；Kaiser 度量表更细：>0.8 非常适合，0.7~0.8 适合，0.6~0.7 比较适合，<0.6 不适合。示例的 .527 就是个勉强过关的例子。

Step 1　决定因子数量：三条判据合着看。其一特征值>1：课件输出表里 44 个成分中有 10 个特征值大于 1（依次 7.280、4.192、3.041、2.548、2.253、1.594、1.318、1.224、1.154、1.044）；其二因子解释的方差百分比：其中 5 个解释了超过 5% 的方差（16.545%、9.527%、6.910%、5.790%、5.121%），第 6 个只有 3.624%；其三碎石图（Scree Plot）：特征值从 7.28 陡降，到第 5 个成分之后曲线明显变平——「肘部」之后都是碎石。综合三判据，决定提取 5 个成分。

Step 2　抽取因子：按决定的因子数量抽取。抽取方法两种：主成分分析（PCA，Principal Component Analysis）和主轴因子分析（PAF，Principal Axis Factoring）。课件例子用 PCA。

Step 3　因子旋转：旋转是为了让载荷形成简单结构——每道题只在少数因子上有大载荷。方法选无旋转、最大方差旋转（varimax，正交旋转：因子互不相关）或斜交旋转（oblimin：允许因子相关）。别忘了 Options 对话框里勾选 Sorted by size 和 Suppress small coefficients（Absolute value below .30）——绝对值低于 .30 的载荷不显示，表才读得清。旋转前 pers03「does a thorough job」在多个成分上都有中等载荷（.510、.434…），旋转后集中在成分 1 上（.717），一眼可判归属。旋转后 5 个成分解释了总变异的 43.89%。

Step 4　因子命名：用旋转后的载荷表（看每列大载荷集中在哪些题上）为成分命名。课件命名出经典的大五人格：

  • C1 尽责性（Conscientiousness）：Item 3, 18, 33, 23, 28, 13, 8, 38, 43
  • C2 外向性（Extraversion）：Item 21, 1, 36, 6, 31, 26, 16, 11
  • C3 神经质（Neuroticism）：Item 14, 9, 19, 24, 34, 39, 4, 29
  • C4 宜人性（Agreeableness）：Item 2, 22, 32, 42, 7, 37, 27, 12, 17
  • C5 开放性（Openness）：Item 40, 30, 25, 44, 20, 15, 5, 10, 41, 35

判读与常见坑：KMO<0.5 不要做；Bartlett 不显著不要做；两者过了也只是「准入」。常见坑一：只认特征值>1 这一条——本例它给出 10 个因子，而方差解释率与碎石图都指向 5 个，最终提取的是 5 个；三条判据要合着用。常见坑二：忘勾 Suppress small coefficients（<.30），载荷表里小数糊成一片，命名无从下手。

演示 3：碎石图——三个判据怎么合着用

曲线取自课件 Total Variance Explained 表列出的前 12 个成分的真实特征值（44 个成分只画课件给出的部分）。拖动滑块改变「特征值>阈值」的阈值线，看保留的因子数怎么变；再对照方差解释率判据和课件「提取 5 个成分」的结论。

3.9 斜交旋转输出：模式矩阵 ≠ 结构矩阵

什么时候用得上：你怀疑几个因子之间本身相关（比如「焦虑」和「抑郁」），于是选了 oblimin 斜交旋转。这时 SPSS 会吐出两张矩阵和一个成分相关性表，读错表就会报错载荷。产出决定：题目归哪个因子、因子之间到底有多相关、要不要回头改用 varimax。

直觉：正交旋转像规定两个声部各唱各的、互不配合；斜交旋转允许声部相互靠拢。一旦允许靠拢，「这道题分给哪个声部」和「这道题跟哪个声部听起来像」就变成了两件事——前者是纯配方（模式），后者混入了声部之间的相互影响（结构）。

术语与公式：模式矩阵（Pattern Matrix）给的是因子载荷——每个题目在自己因子上的唯一归属系数，命名和归组用它；结构矩阵（Structure Matrix）给的是因子与项目之间的相关性——已经混入因子间相关的影响。课件输出里两张表并列：模式矩阵中 pers03 在成分 1 载荷 .720，结构矩阵中同题对成分 1 是 .733。换算关系用一个课件里的例子算清楚：Item1 与 Factors 的相关——Varimax 下对 Factor1 为 0.6、对 Factor2 为 0.1；换成 Oblimin 且两因子相关为 0.4 时：

对 Factor1：0.6×1 + 0.1×0.4 = 0.64　　对 Factor2：0.6×0.4 + 0.1×1 = 0.34

也就是说：结构 = 模式系数乘以因子相关矩阵之后的结果；因子间相关不为 0 时，两列结构值都会被「抬高」。成分相关性表（Component Correlation Matrix）报告旋转后因子间相关，课件例子里相关非常低（介于 -.200 到 .182）——Oblimin 旋转后的因子之间的相关非常低，或许采用 Varimax 会更好。

判读与常见坑：成分相关普遍 很低（|r|<.30 左右）→ 用回 varimax 更简洁；中等以上相关才值得留在斜交。常见坑：斜交旋转后拿结构矩阵的数字当「载荷」报告、或用它来决定题目归属——归属要看模式矩阵；结构矩阵里的数是被因子间相关「串了味」的相关。

4. 本讲在课程里的位置

上一讲（第四讲）讲完效度三类证据，留下的问题正是「结构效度怎么用数据算出来」。这一讲给出了答案的前半：EFA 用数据驱动的方式把题目背后的因子挖出来——特征值、碎石图、旋转、命名，一条链跑通，大五人格就是现成的成品。但 EFA 的结果依赖这一份数据和你选的旋转方式，「探索出来的结构」还不等于「结构成立」——它需要被理论驱动的验证性因子分析（CFA）检验：按理论指定题目归属，看模型拟合、做载荷的显著性检验。这是第六讲要解决的事。

0. 开场白：上一讲让数据自己说话，这一讲轮到你验收

第五讲用探索性因素分析（EFA）把量表的维度摸了出来：几个因子、每题挂在哪个因子上。但那是数据自己长出来的结构——软件说分两个因子就两个，万一换个样本就变样，万一分出来的因子毫无心理学意义呢？探索给你的是图纸草稿，草稿不能直接当验收报告用。

这一讲的验证性因素分析（CFA）把主动权交回给你：你先按理论画好图纸——几个因子、每题挂在哪、因子之间什么关系，全都事先指定；然后让数据来验收这张图纸。EFA 是探索，CFA 是验收，两者方向相反、缺一不可。

本讲路线一句话：先弄清 EFA 和 CFA 差在哪，再拆开 CFA 的核心等式与模型识别，然后学会读拟合指标，最后上 R（lavaan）和 Mplus 实操。

3.1 EFA 快速回顾：数据自己长出来的结构长什么样

什么时候用得上：你已经收到一批量表数据，但说不清它该分几个维度。EFA 让软件自己去找结构：先做前提检验，再抽因子、旋转、命名。它产出的因子结构，正是这一讲 CFA 要拿去验收的图纸草稿。跳过前提检验硬做，后面抽出来的东西自己都不敢信。

先重温直觉：EFA 的姿势是把一堆题目丢给软件，每个因子都试着连接所有题目，最后按载荷大小“认亲”。开跑之前有两道安检——Bartlett 球形检验（原假设是变量各自独立；检验显著 = 拒绝独立，说明变量间有相关，可以做因子分析）和 KMO 检验（看变量间相关相对偏相关够不够强，取值 0～1，越接近 1 越好；0.7 以上效果比较好，0.5 以下不适合做因子分析）。

术语与流程四步走：①前提检验（KMO 大于 0.5、Bartlett 显著、相关矩阵大多大于 0.3）→ ②抽取因素（主成分分析法或主轴因素法，按特征根大于 1、总方差解释率、碎石图定个数）→ ③因子旋转（varimax 正交 / oblimin 斜交）→ ④因子命名（按题项内容起名）。课件示例数据 KMO=0.550，落在“勉强可做”区，配合 Bartlett 显著（χ²=73.582，p<.001）就能做，但谈不上理想。

课件原话：CFA 已知数据结构——研究者指定潜在因素数量、指定哪个题目属于哪个因子、把与给定因子无关的载荷全部设为“零”、因子相关可以直接估计（无需旋转）。这就是“验证”两个字的含义。

① 看理论意义（因子理论上该不该相关）→ ② 看旋转后因子相关矩阵稀不稀疏（相关大多 < 0.3 才算稀疏）→ ③ 看双载荷（交叉载荷）严不严重，交叉载荷一般由因素间相关较高导致 → ④ 拿不准就用 CFA 验证。心理测量里的因子（如外倾性和焦虑）大多相关，默认斜交更稳。

小冷知识：oblimin 的模式矩阵里载荷超过 1，正常吗？

课件作业问题里有人看到载荷 1.020 就吓得改回正交旋转。其实斜交旋转后有两套载荷——模式矩阵（回归系数）和结构矩阵（相关系数）。载荷能超过 1 有三种解释：① 分析用的是协方差矩阵（变量未标准化），载荷其实是协方差、回归系数，不必局限在 [-1, 1]；② 斜交旋转后模式载荷是回归系数不是相关系数，即使分析的是相关矩阵，模式载荷也可以超出 [-1, 1]；③ 罕见的 Heywood case（共同度超过方差，常见于变量太少、撑不起要抽的因子数），软件会报错——这才是真正要警惕的情况。所以“看到 1.020 就改正交”是没必要的。

3.2 PCA 与 FA：方向正好相反，别混为一谈

什么时候用得上：你在 SPSS 里点「因素分析」，默认抽取方法其实是主成分分析（PCA）。报告结果前必须说清自己用的是 PCA 还是真正的因素分析（FA），因为两者方向相反、含义不同。手头有相关矩阵或原始数据、想降维或找结构时，先想清楚要的是哪一种。

直觉上，PCA 是在多维空间里换一个坐标系：第一根轴（主成分 1）指向数据最分散的方向，第二根轴与它垂直、承接剩余方差最大的方向，以此类推。主成分是“算出来”的坐标轴，不是“藏在题目背后”的心理构念。FA 则反过来，假设题目是被少数几个共同因素带动的，每题还带一份解释不了的残差。

术语与公式：PCA 的数学本质是对协方差矩阵做特征分解。

S = PΛP′，第 k 个主成分是 zk = Xpk

其中 S 是题目间的协方差矩阵，P 是特征向量矩阵，Λ 是特征值矩阵，X 是题目分数矩阵。PCA 里题目数 = 成分数；FA 里因素数 < 题目数，题目是因素的线性组合、带残差。

用题目预测成分

成分是题目的线性组合

题目数 = 成分数

没选中的成分不是不存在，只是被忽略

因素分析 FA

用因素预测题目

题目是因素的线性组合，带残差

因素数量 < 题目数量

承认每个题目都有解释不了的部分

判读与常见坑：PCA 结果要按“成分”解释，FA 结果才按“因子/构念”解释。常见坑：把 SPSS 默认的 PCA 输出直接当成因素分析来解释——方向是反的，含义完全不同。

3.3 CFA 的核心等式：一个等式管到底

什么时候用得上：图纸画好了（几个因子、每题挂哪），接下来要用一个数学框架把“模型算出来的题目关系”写出来，才能跟真实数据比。这个框架就是 Σ=ΛΦΛ′+Ψ。看懂这四个字母，CFA 输出里的大部分表你都知道在算什么。

直觉：CFA 拿着你画的图纸，“仿制”出一套题目之间的协方差，再跟真实数据的协方差对账。仿制得越像，图纸越好。

Σ = ΛΦΛ′ + Ψ

Σ 模型隐含的协方差矩阵

模型算出的题目间协方差，目标是逼近真实协方差

Λ 因子载荷矩阵

每题挂在哪个因子上、挂得多紧

Φ 因子协方差矩阵

因子之间什么关系，可以设为零也可以估计

Ψ 独特方差

每题里因子解释不了的误差部分

有个反直觉的点：方差总能被完美复制，协方差不能——所以 CFA 比拼的就是模型重生成的协方差与真实协方差贴得多近。

判读与常见坑：Φ 里的因子相关可以自由估计也可以固定为零，这是“斜交 vs 正交”在 CFA 里的对应设置。常见坑：把 Ψ（误差）当成要消除的东西——它不是缺陷，是模型承认“每题都有解释不了的部分”的诚实条款。

3.4 模型识别：参数够不够用，决定有没有解

什么时候用得上：设计量表、画图纸时就要想：每因子放几道题？数据能提供的信息量是固定的——p 个题目只有 p(p+1)/2 个独特元素（方差 + 协方差）。模型要估的参数不能比这多，否则压根没有解。这道算术决定你的模型能不能跑、能不能检验。

直觉：你手里只有一沓固定大小的“信息钞票”，模型每估一个参数就要花一张。参数比钞票多，账就做不平。

3.5 给潜变量定标尺：两种等价方法，顺带认识路径图四符号

什么时候用得上：因子是潜变量，本身没有单位——“因子载荷是 0.7”到底高不高，得先知道尺子是什么。CFA 里必须给每个潜变量定一把尺，软件才能开算。看懂别人论文里的路径图，也需要认识四个符号。

直觉：“小明比小红高 3”没有意义——3 什么？厘米还是寸？潜变量也一样，得先定尺子。两种定法完全等价，拟合结果一模一样：

固定载荷法（Marker Item）：把某题（通常第一题）的因子载荷设为 1　｜　固定方差法（Z-Score）：把因子方差设为 1（均值 0、方差 1 的标准尺）

固定载荷法是让因子借用第一个题目的量纲；固定方差法是直接给因子套上标准尺，但它不能用于高阶因子模型。

路径图四个符号：椭圆 = 潜变量（因子、构念）；矩形 = 观察变量（题目、指标）；单箭头 = 影响方向；双箭头 = 协方差（相关，不能做因果解释）。

判读与常见坑：两种定标尺方法没有优劣之分，拟合程度一模一样。常见坑：报告里不说明用了哪种定标尺，读者没法判断你载荷的量纲；以及在高阶因子模型里硬用固定方差法——软件会直接出错。

3.1 难度：一道题有多难，三种算法任你选

什么时候用得上：测验改完了，想知道每道题出得合不合适。难度是第一把尺子：被试完成该项目时所遇到困难的程度。它决定整卷分数往哪儿堆、还能不能区分人，也是后面算区分度上限的前提。不做难度分析，你可能把一张人人都对的送分题当宝留着。

直觉：难度不是“这题折磨人的程度”，而是“多少人能闯过去”。所以符号 P 是通过率——先记住这个坑：P 越大越容易，别反过来。

二分·通过率法：P = R / N　｜　二分·极端分组法：P = (PH + PL) / 2　｜　非二分：P = x̄ / xmax

P 是通过率，R 是答对人数，N 是被试总数；极端分组法按总分取前 27% 与后 27% 两组、算两组通过率的平均；非二分项目用项目均分 x̄ 除以满分 xmax。

难度还能换算成等距量：样本大时分数近似正态，通过率对应正态曲线下的面积，反过来查出分界点的 Z 分数。通过率 50% → Z=0；通过率 84% → Z=−1（84% 的人通过，分界点在均值左边一个标准差）。ETS 在此基础上做线性变换：

Δ = 13 + 4Z　（Z 为负时查右尾面积；Δ 的均值是 13，大致区间 1～25，对应 Z 取 ±3）

Z 分数 = 0.00　　Δ = 13 + 4Z = 13.00

3.2 难度定多高？看测验干什么用

什么时候用得上：出卷之前就要定每题的目标难度。难度没有放之四海皆准的“最佳值”——常模参照想拉开差距就取 0.5 附近，达标测验只管会不会，选拔考试直接贴着录取率出。目的定错，整卷白出。

直觉：同样是跑步计时，招聘短跑运动员要卡到只有几人达标，体质测试只要大多数人及格——标准跟着目的走。

测验目的难度怎么定
尽可能区分被试的个体差异难度 0.5（0.3～0.7 之间）
检测是否达到教学目标不必过多考虑难度
选拔和录用人员难度应接近录取率

三条注意事项：①速度测验不宜太难，且各题难度应基本相当（考的是快慢不是深浅）；②难度测验最好 0.5 左右；③任何测验都要防止有人得满分——满分说明最高水平没测出来。

判读与常见坑：难度还决定分数分布的形态——题目太难→正偏态（分数堆在低分端）；题目太易→负偏态（堆在高分端）；太难或太易都会让分数全距缩小，而难度 0.5 附近分数分布最广、最拉开差距。常见坑：达标测验也去追求 0.5——教学目标都该达成，人人高分是正常的，别机械套 0.5。

3.3 区分度之一：项目鉴别指数 D

什么时候用得上：难度告诉你题目难不难，区分度告诉你题目有没有用：测验项目对被试心理品质水平差异的区分能力。理想状态是水平高的得高分、水平低的得低分。想知道哪道题该改该删，先算 D。

直觉：把总分最高的 27% 和最低的 27% 拉出来各答一遍这道题。高分组都对、低分组都错，这题眼睛毒；两组差不多，这题白问。

3.4 区分度之二：相关法——按变量类型选公式

什么时候用得上：不想分组、想用全部数据时，把题目得分（或 0/1 通过与否）和总分（效标）求相关，就是相关法区分度。四种公式对应四种变量组合——先看题目和效标各是二分还是连续，再选公式。

直觉：相关法问的是“这道题的得分跟着总分走不走”。跟着走 → 跟总分一条心 → 有区分度；各走各的 → 这题测的不是总分测的东西。

3.5 难度卡死区分度的上限；区分度是相对的

什么时候用得上：抱怨“这题 D 怎么才 0.2”之前，先看看它的难度——P=0.95 的题就算出类拔萃，D 也到不了 0.25。评估区分度前先用 Dmax 算出这道题的“天花板”，才知道它是真的差还是被难度卡死了。

直觉：人人都答对的题，高分组低分组通过率都顶到 1.00，D 必然是 0——不是题目没本事，是难度没给它留发挥空间。

Dmax = 2·min(P, 1−P)　（P=1.00 → 上限 0；P=0.90 → 上限 0.20；P=0.50 → 上限 1.00；P=0.10 → 上限 0.20）

演示：Dmax 曲线——悬停各点看不同难度下的区分度天花板

课件配套思考题：效度和区分度什么关系？区分度是效度的必要底座——题目分不开人，整卷不可能有效度；但每题区分度都高，也不保证测的就是你想测的构念。

判读与常见坑：区分度是相对的：①不同方法算出的数值不同；②样本量影响相关法的显著性；③分组标准影响鉴别指数；④被试越同质，区分度越低——大家水平差不多，还区分什么。常见坑：拿两个不同样本、不同方法算出的 D 直接比大小，比出个“这题退步了”的假结论。

3.6 猜测问题与猜测率：蒙对的分要不要扣

什么时候用得上：选择题哪怕完全不会，K 选 1 也有 1/K 的概率蒙对：二选一 50%，四选一 25%，五选一 20%。要不要把蒙对的部分校正掉，出卷和计分前就得决定——两套公式、一堆理由，正反都有。

直觉：四个选项瞎蒙，运气好能白捡 25 分。校正公式相当于“查账”：把靠运气蒙对的部分从分数里扣回去，让分数只反映真本事。

校正项目难度：CP = (KP − 1) / (K − 1)　｜　校正被试分数：S = R − W / (K − 1)

P 是原始难度，K 是选项数；R 是答对数，W 是答错数。公式的前提假设：不会的人完全随机猜——这正是全部争议的根源。

演示：猜测校正计算器——拖 R、W、K，看蒙对的分怎么被扣回去

校正后得分 S = 46.7（原始 60，蒙对的部分被扣回去）

校正的理由

可避免降低测验信度；可反映被试真正水平；可培养诚实美德；比较公平。

不校正的理由

公式基本假设不成立；答完全部题目时校正无实质作用；不校正对信度并无重大影响；校正有时出现无法解释的现象（如负分）；合理猜测是值得鼓励的好习惯。

判读与常见坑：两派理由都要背——作业考过优缺点对比。常见坑：校正后出现负分就慌——这正是“校正有时出现无法解释的现象”那条理由的现实版，不是你算错了。

3.7 选择题的项目分析：连错误选项一起审

什么时候用得上：难度和区分度审的是“正确答案”，选择题还有第三层：四个诱答选项有没有各尽其责。总分前 27% / 后 27% 分组后逐题看选项分布，能发现答案有歧义、诱答没迷惑性这类只看对错看不出的问题。

直觉：错误选项是陪跑的，但陪跑也有 KPI——每个错误选项都得有人选，不然等于三选一。评估四件事：难度得当？有区分度？有无缺陷？诱答选项是否都有效？

看到的现象说明什么
正确答案被所有人选择该题太容易
某个错误答案没有任何人选不具备迷惑性（应有 2% 以上的人选择）
所有人都选了同一错误答案答案错了，或者教错了
高分组的选择集中在两个答案上本来就有两个答案，或另一答案也有道理
高分组与低分组对正确答案的选择率相当该题与被试水平无关
未作答人数较多，或各选项人数相当题太难、没讲过或题干不清

课件质量分析表示范：第 1 题难度 0.71、D=0.42，好题；第 3 题正确答案是 D，但高分组选 D 的比例反而低于低分组（rpb=−0.04，D=−0.06），必须重做。

判读与常见坑：六条规则对着选项分布表逐条套，别只盯正确答案的选择率。常见坑：诱答选项“没人选”不当回事——它让题目悄悄从四选一变成三选一，猜测率跟着变了。

3.8 项目功能差异（DIF）：公平性检查

什么时候用得上：同一道题，男生女生答对率不一样——这算性别歧视吗？不一定：可能只是两组能力分布不同。DIF 分析就是先把能力匹配上，再看还有没有差异。编写正式量表、跨群体施测时，这道检查不能省。

直觉：两个班平均分差 10 分，可能是 A 班学霸多，不能说明某道题偏心。DIF 看的是“把总分拉平之后”，这道题对两个群体还是不一样难吗？只有匹配了能力层级仍存在差异，才算 DIF。

四步流程：①数据准备（抽子群体，如男/女）→ ②准备性分析（删掉可能存在 DIF 的题）→ ③探索性分析（用删后的测验再做 DIF）→ ④差异根源分析（探索差异的性质与来源）。

四种检测方法：方差分析法（看组间差异是否显著）；项目难度比较法（分组各算 Δ 后做散点图，离对角线远的题可疑）；卡方检验法（答对答错与群体是否独立）；项目反应理论方法（项目特征曲线有无差异）——最后一种就是第八讲 IRT 的伏笔。课件用 read.xlsx 示范的流程 = T 检验 + 分性别算 Δ 画散点图 + 分性别算题总相关。

判读与常见坑：两组通过率有差异本身不算 DIF——可能只是能力分布不同。常见坑：跳过 DIF 分析（作业里真有同学没做）；以及 T 检验和方差分析结果对不上就硬写——两种方法得到的结果应该一致，对不上多半是数据格式或分析设置错了，先回查再下结论。

3.1 经典测量理论的四大局限

什么时候用得上：写论文或答辩时被问「为什么不用 IRT」，得先把 CTT 的短板说清楚；自己选方法前，也要先知道旧尺子哪里量不准。手头是已经按第七讲算出的难度、区分度、信度。用它做的是「要不要升级工具」的决定。不先看清局限，就可能拿着随样本变的参数去建一劳永逸的题库。

先别急着记四条，去鞋店逛一圈。鞋盒上只印一个「42 码」，可你的左脚右脚、早晨晚上并不一样——标签笼统，还把所有人当成同一只脚；这家店的「42 码」和那家店的「42 码」根本不是一个标准，拿着 A 店的尺码去 B 店买鞋，对不上号。

再听导购一句「这鞋偏不偏小，得看今天来店的顾客都穿多大」——尺码全由当下这批人定义；至于「磨不磨脚」，理论上得再买一双一模一样的鞋穿过才知道。CTT 的四个局限，生活里早有对应的别扭：误差人人共享、难度与水平两套标准、参数随样本漂移、精度靠平行测验撑着。

CTT 用起来顺手，但课件一上来就点它四处软肋。逐条看，每条都配了课件的思考气泡——先自己想一想，再往下读。

  • 局限一：信度估计精度不高。依赖的假设不一定成立，平行测验（靠再造一份等价卷子来估误差的做法）本身存疑。课件思考气泡：哪些假设？什么是平行测验？什么是 τ 等价测验？
  • 局限二：误差指标笼统单一、不精确。一份卷子只给一个标准误，所有被试测量误差等同。课件思考气泡：想一下什么样的被试测量误差更大？想一下我们可不可以给每个被试估计一个测量误差／信度？
  • 局限三：各种参数的估计对样本的依赖性大。样本对总体必须具有代表性，否则参数失真。课件思考气泡：思考一下「四度」（难度、区分度、信度、效度这些指标）对样本的依赖性。
  • 局限四：各参数指标之间的配套性较差。试题难度和被试水平不在同一个评价系统——一个是通过率，一个是卷面分。课件思考气泡：90 分的被试适合做什么难度的题？

带着这四条看本讲：IRT 的四大优良性质（3.7）几乎是一一对应的解药。先立一张对照卡，本讲读完再回头看：

CTT（第七讲及以前）

  • 难度 P、区分度 D：换一批被试就变。
  • 误差：全卷一个 SE，人人共享。
  • 尺子：难度是 0～1 通过率，人是卷面分，两把尺。
  • 分组：高低分组只有前 27%／后 27% 的粗格子。

IRT（本讲）

  • 题目参数 a、b、c：跨群体不变。
  • 误差：SE(θ)，每个水平各是各的。
  • 尺子：b 与 θ 共用一把 Z 分数尺。
  • θ 连续尺上每一点都能查到题目信息。

常见坑：把「所有被试误差等同」当成事实——它只是 CTT 只能给一个笼统误差指标，不代表每人误差真的一样。能力两端（题目对他太易或太难）的被试，误差其实更大，这正是课件气泡要你自己想出来的答案。

3.2 潜在特质理论：先把「人」放上尺子

什么时候用得上：想精确谈论「这个人的水平多高」，而不满足于一个卷面总分时。手头是被试在题目上的作答。用它把人定位到一条公共量尺上，后续所有 IRT 模型都在这条尺上展开。没有这一步，题目参数和人的水平永远说不到一块儿——局限四无解。

先想「身体健康」：它看不见、摸不着，没有物理形态，但它实实在在制约你爬几层楼会喘。心理量也一样——「数学能力」没有物理形态，却制约你能不能解出这道题。这类制约人的行为的心理特征、又没有明确物理或生理形态的东西，就叫潜在特质（Latent trait）。

那影响一种行为的特质只有一个吗？往往不止。把对某一特殊行为的发展起作用的所有潜在特质的集合，叫潜在特质空间（Latent trait space）：

H = (θ1, θ2, θ3, …, θk)

符号一句话：H 是潜在特质空间；θj 是第 j 个维度上的特质水平；k 是空间的维度个数。课件气泡把心理测量关心的两件事点得很清楚：一是潜在特质空间的维度 k＝?（要测几个特质），二是潜在特质的水平 θ＝?（这个人在该特质上有多高）。本讲后续的模型都只放一个 θ（单维，k＝1）。

常见坑：把 θ 读成卷面分或百分比——θ 走的是标准 Z 分数量表（课件 3.4 会再强调），θ＝0 是平均水平，θ＝1.5 读作「高出平均水平 1.5 个标准差」。也别把「潜在」听成「不存在」：它只是没有物理形态，不是没有作用。

3.3 从题总相关到项目特征曲线（ICC）

什么时候用得上：想完整描述「能力越高、这道题答对可能性越大」这条规律，而不是只用一个相关系数打发时。手头是各水平被试在这道题上的通过情况。用它画出题目自己的「性能曲线」，产出「这道题对哪些水平的人最有分辨力」的判断。不做这一步，题目信息就压缩成一个数，细节全丢。

课件先给三条观察（原文高亮）：能力低的被试在题目上正确作答的概率较小；能力高的被试正确作答的概率较大；因此随着能力从低到高，题目正确作答的概率也在从小变大。

CTT 里表达「题目与能力关系」的工具是题总相关——题目得分与卷面总分的相关，它也能体现题目正确作答率和测验卷面总分的关系。但课件气泡当场追问：用题总相关来表达上述观察，缺陷是什么？缺陷在于：它把整条变化规律压缩成一个相关数。你问它「能力恰好是某个水平的被试，答对概率是多少」，它答不上——一个平均坡度替代不了整条山路。

IRT 的改法干脆利落：换自变量、定因变量。用能稳定反映被试水平的潜在特质变量 θ 替代卷面总分作为回归曲线的自变量；用题目正确作答概率 P 作为因变量。这条曲线就是项目特征曲线（Item Characteristic Curve，ICC），记作 P(θ)：

P = P(θ)　（自变量：潜在特质 θ；因变量：正确作答概率 P）

常见坑：把 ICC 的纵轴读成分数、横轴读成卷面总分——纵轴永远是概率（0～1），横轴是 θ（Z 分数尺）。坐标轴读错，整张图就全盘读错。

3.4 项目特征函数 ICF：给 S 形曲线装上三个旋钮

什么时候用得上：拿到 0/1 作答矩阵要给每道题建模型，或要读懂软件输出的 a、b、c 时。手头是 ICC 的形状与位置。用它把「曲线长什么样」翻译成三个可解释的参数，产出对每道题「多难、多能区分、能不能蒙」的判断。不懂参数含义，软件给的数字就只是一排乱码。

ICC 长什么样？一条 S 形曲线：左端贴地趴平——能力再低的人也有点答对机会；右端封顶——能力再高也到 1；中间最陡。项目特征函数（Item Characteristic Function，ICF）就是这条曲线的函数式，课件给了两种形式。

第一种，正态卵形函数（把正态分布从 −∞ 积分到 a(θ−b)）：

P(θ) = C + (1−C)·∫−∞a(θ−b) (1/√(2π))·e−t²/2 dt

第二种，Logistic 函数：

P(θ) = C + (1−C) / (1 + e−1.7a(θ−b))

符号一句话：θ 潜在特质水平，标准 Z 分数；a 区分度，看曲线拐点（最陡处）的斜率；b 难度，拐点的横坐标位置；C（小写 c）猜测参数，又称伪机遇水平，是曲线的下渐近线（曲线左端无限贴近但达不到的那条水平线）；1.7 是尺度常数，作用是让 Logistic 曲线的形态尽量贴近正态卵形——所以课件把两式并排给出，两者可以互相替代，Logistic 好算，实际中更常用。

课件在 Logistic 式旁边留了一个气泡：为什么是这个形式？思考 logistic regression。逻辑回归的套路是：拿一个线性组合，送进 S 形函数，压成 0～1 之间的概率。IRT 这里一模一样——线性部分是 1.7a(θ−b)，送进同一个 S 形骨架 1/(1+e−z)：b 像「截距」，定曲线中心；a 像「斜率」，定曲线陡峭。两者同构，只是自变量从「某某预测指标」换成了潜在特质 θ。

拐点处（θ＝b）的概率正好是 c＋(1−c)/2——一半的「非猜测空间」被越过；课件图示例给出了一组参数供对照：Pseudo-Guess c＝0.13、Discrimination＝1、Difficulty＝0.5。

3.5 三条不同难度的 ICC：曲线只会平移

什么时候用得上：组卷挑题、要在几道候选题之间比难度时；或拿到一张画了多条 ICC 的图需要快速读图时。手头是各题的 b。用它一眼看出谁易谁难，产出选题的先后顺序。不会读平移，就会把「难题」当「好题」。

固定 a、固定 c，只让 b 变，会看到什么？整条 S 曲线左右平移，形状纹丝不动：b 越小曲线越靠左（越容易），b 越大越靠右（越难）。三条曲线各自的拐点落在 P＝0.5（本图取 c＝0）的横线上，横坐标就是各自的 b。

3.6 参数估计：从作答矩阵到 a、b、c、θ

什么时候用得上：拿到真实作答数据要跑 IRT，或读论文的参数表想搞懂「这些数从哪来」时。手头是 n 个被试 × k 道题的 0/1 矩阵。用它同时估出题目参数和被试水平，产出可入库、可解释的 a、b、c、θ。不懂估计逻辑，就没法判断「软件给的数能不能信」。

先把数据摆好：把每个被试每道题的对错记成 0/1，排成作答反应矩阵 U。最大似然的直觉一句话：挑一组参数，让「你实际看到的作答模式」出现的可能性最大。像听到走廊一串脚步声猜是谁——你挑的答案是「最可能踩出这种声音的那个人」。

U = (uij)k×n　（题目 i = 1,2,…,k；被试 j = 1,2,…,n；uij 取 0 或 1）

每个格子里的对错概率由 ICF 给出（下标换成「第 i 题、第 j 人」）：

Pij = Ci + (1−Ci) / (1 + e−1.7ai(θj−bi))

把所有格子的概率连乘，取对数，得对数似然函数：

ln L(U|θ, a, b, c) = ln ∏i ∏j Pijuij · (1−Pij)1−uij

符号一句话：uij 第 j 人在第 i 题的作答（1 对 0 错）；Pij 该人在该题的答对概率；L 似然——参数给定时「看到这批作答」的概率；∏ 连乘号，把 k×n 个格子的概率乘起来。答对了乘 Pij，答错了乘 1−Pij。

要估的参数有多少个？每道题 3 个（a、b、c），每个人 1 个（θ）——k 道题、n 个被试，共 3k+n 个参数。手算没戏，交给软件：老牌专用软件有 LOGIST、BILOG、MicroCAT 等；R 里约有 45 个 IRT 相关包，挑顺手的用。

3.7 四大优良性质：每个局限都有解

什么时候用得上：要向别人（或自己）论证「为什么值得为 IRT 投入」，或在题库建设、测验编制立项前评估收益时。手头是 3.1 那四条局限。用它把「性质 → 用途」对应起来，产出立项或选型的理由。跳过这节，IRT 就只是一堆公式，看不出生产力。

想象一家连锁超市。商品条码不因你在哪家分店扫码而变——所以才能建中央商品库，这是「不变性」；各国价签币种不同，汇率一换就能对上——不同试卷放到同一量纲，这是「量表可选择性」；全国门店统一用同一把尺标注尺寸，而不是各店自定义——b 与 θ 共用一把尺，参数才能配套。

最后，营养标签按你实际买的那份标注，而不是全店一句「总体还行」——IRT 的信息函数也一样，每个 θ 各有各的精度。四条性质合起来是同一件事：把「按店浮动」升级成「全国统一、按人精确」。

课件把优良性质列了四条，逐条都能接住 3.1 的一个局限，且每条旁边都有气泡点明用途。

性质一：题目参数的跨群体不变性。IRT 的题目参数估计独立于被试样本；被试能力参数估计独立于题目样本。换个群体重测，题目还是那个题目。课件气泡：方便建题库、方便自适应。

性质二：潜在特质量表的可选择性。潜在特质 θ 的量表可以任意选择，因此可以使不同被试、不同试卷的所有潜在特质参数与题目参数定义在同一度量系统上，枢纽就是 Logistic 里的线性部分：

a(θ − b)　（θ 与 b 同一把尺，才能直接相减）

课件气泡：方便做测验等值——这是第 12 讲的主角的钥匙，先收好。

性质三：参数设计的科学性。三条：题目难度参数 b 与被试潜在特质参数 θ 定义在同一度量系统上；区分度参数与难度参数相互独立；伪机遇参数 c 具有实证性（从实际作答数据估出来，不是拍脑袋设定）。课件气泡：方便为被试选题、方便为各难度编高区分度的题、反映实际猜测情况。

性质四：信息函数概念的引入与信息函数的可加性。每道题在每个 θ 上都有一个信息量：

Ii = Pi′(θ)² / [Pi(θ) · Qi(θ)]　　SEi = [Ii(θ)]−1/2

I(θ) = Σi=1k Ii(θ)　　SE = [I(θ)]−1/2

符号一句话：Pi′(θ) 是第 i 题 ICC 的导数（曲线在该点有多陡）；Qi(θ) = 1 − Pi(θ) 答错概率；Ii 第 i 题的信息量；I(θ) 测验信息量——各题信息直接相加（可加性）；SE 标准误，信息量取倒数再开方。曲线陡（a 大）且 P 接近对错各半时，信息最多。

这一条正面接住局限二（也顺手了结局限一）：课件气泡当初问「可不可以给每个被试估计一个测量误差／信度？」——现在答案是「能」：SE 是 θ 的函数，你的水平附近题目密集，你的 SE 就小；每人有自己的误差，不再共用一个笼统数，也不再靠「再造一份平行卷」来谈精度。

CTT 的局限（3.1）IRT 的性质（本节）兑现的用途（3.9）
③ 参数估计对样本依赖大① 题目参数跨群体不变性建题库、自适应选题
④ 难度与水平不同一系统② 量表可选择性（a(θ−b) 同一度量系统）测验等值
④ 配套性差③ b 与 θ 同尺、a 与 b 独立、c 实证为被试选题、编高区分度的题、反映实际猜测
② 误差笼统单一（① 信度精度不高）④ 信息函数可加、SE(θ) 人人不同常模／目标参照编制、按 θ 选题

常见坑：把「不变性」夸成「换任何样本算出的数字一位不差」——课件说的是「估计独立于被试样本／独立于题目样本」，指参数由题目与 θ 的关系决定、不随样本构成漂移；别拿它当「绝对不动」的字面理解。另一个坑：I(θ) 是测验信息，Ii 是题目信息，汇报时别混用。

3.8 模型族：Rasch、1PL、2PL、3PL 与各自的信息函数

什么时候用得上：跑软件前要选模型——「要不要猜测参数？各题区分度当不当它相等？」——以及拿到输出后要对照模型查公式时。手头是对数据的判断（有没有猜、区分度是否参差）。用它选定参数个数合适的模型，产出「这套数据用几参数模型」的决定。选错模型，参数解释就拧了。

把 3.4 的三个旋钮逐个焊死，就得到一族模型，参数从少到多排开。课件用一张对照图并列了它们的 ICF 与信息函数（并注明出处：Rasch, 1960；Hambleton & Swaminathan, 1995）。

Rasch：P(θ) = 1 / (1 + e−(θ−b))　　1PL：P(θ) = 1 / (1 + e−1.7(θ−b))

2PL：P(θ) = 1 / (1 + e−1.7a(θ−b))　　3PL：P(θ) = c + (1−c) / (1 + e−1.7a(θ−b))

Rasch 与单参数模型（1PL）只留 b——假设各题区分度相同、不设猜测参数；两参数（2PL）放开 a；三参数（3PL）再放开 c。模型越简单越好估、越复杂越贴数据，代价是需要更多数据。

每个模型配自己的信息函数（把 ICF 的导数代入 3.7 的 Ii 公式整理出来的结果）：

1PL：Ii(θ) = Pi(θ)·Qi(θ)

2PL：Ii(θ) = a²·Pi(θ)·Qi(θ)

3PL：Ii(θ) = a²·[Pi(θ) − c]²·Qi(θ) / [Pi(θ)·(1−c)²]

符号一句话：a² 说明区分度翻倍、信息量翻四倍；3PL 里的 [P−c]² 与 (1−c)² 说明猜测参数会把整条信息曲线压矮——能蒙对一部分的题，提供的信息天然少一截。信息量峰值都落在 θ≈b 附近：题目最卖力的时候，正是考生水平与题目难度打照面的时候。

演示二：信息函数实验室——钟形曲线与它的峰

切换模型、拖动参数，看信息量 I(θ) 的钟形曲线怎么变；勾选叠加第二题，验证 I(θ)＝ΣIi 的可加性。

判读：把 P＝Q＝1/2 代入 2PL 信息函数得 I＝a²/4——a＝1 的题峰值 0.25，a＝2 的题峰值 1.00，1PL 各题峰值一律 0.25（区分度被焊死成相等的代价）。峰值附近 SE 最小，离 b 越远信息越少、误差越大。

常见坑：以为信息曲线是「题目难度分布」——纵轴是信息量，不是人数也不是概率；同一条 ICC（3.4 演示一）换算成信息函数就成了钟形，两座山别认混。

3.9 应用：IRT 能帮你干的五件事

什么时候用得上：编制或改版测验、建题库、上机做自适应测验时——先弄清 IRT 在每个场景里到底替你干什么。手头是已估好参数的题库或一份待编的测验。用它决定「编哪种测验、按什么标准凑题」，产出明确的编制方案。不看用途就上公式，容易编出一个「参数漂亮但不好用」的测验。

五件事合起来，像请了一位私人教练。他先摸你的底子（估计 θ）；他的动作库里每个动作都标好了强度和难度（题库里每题存着 a、b、c 和信息函数）；每次只挑「对你刚好有挑战」的动作（按信息量选题）。

你要参加达标测试，他按「及格线」安排训练（目标参照划合格线）；你想知道自己在同龄人里的位置，他拿常模给你比（常模参照缩小误差）；练完还告诉你哪块是短板（认知诊断）。教练做的一切，IRT 在考试里都能做。

课件列了五项应用，每项背后都站着 3.7 的某条性质。

① 对题库建设的特殊贡献。入库的不只是题干和答案，还有四个字段：难度、区分度、猜测度、信息函数。靠性质一（不变性），这些参数不随招募样本漂移，存进去的题过两年换批人还能用。

② 常模参照测验的编制（跟别人比、看相对位置的那种测验）。目标：缩小误差。路线：根据最大允许测量误差求最小信息量——把 SE＝[I(θ)]−1/2 反着用：先定「SE 不能超过多少」，换算出「I(θ) 至少要多少」，再按可加性凑题目。

③ 目标参照测验的编制（跟标准比、看达没达标的那种）。核心任务是划合格线：取「刚够格」的 θ，算出该水平在各题上的答对概率，平均起来就是合格线：

πc = (1/k)·Σi=1k Pi(θ)

符号一句话：πc 合格线（答对比例的标准）；k 题数；Pi(θ) 第 i 题在指定 θ 上的答对概率。

④ 计算机自适应测验的编制（Computerized Adaptive Testing，CAT）。规则一句话：根据能力 θ 推荐题目——按你当前估计选信息量最大的题，答题像通关：答对下一题变难，答错下一题变易，几步就锁定你的水平。靠性质一（题库参数可复用）＋性质四（每个 θ 上都能挑到信息最大的题）撑腰。课件气泡：方便自适应。

⑤ 认知诊断测量模型的发展基础。认知诊断关心作答的认知加工过程——不只问「多高」，还问「哪块会哪块不会」；IRT 的概率框架是这类模型生长的地基。

演示三：CAT 流程示意——通关式测验怎么走

点「开始」后，用「答对了／答错了」模拟作答，看 θ 怎么被一步步逼近、题目难度怎么跟着你走。演示里 θ 按固定步长 ±0.5 更新、六题封顶，仅示意「对则变难、错则变易」的循环；真实 CAT 用最大似然等方法估计 θ，并在信息量达标时停止。

判读：合格线 πc 算出来后通常落在 0.5～0.9 区间视测验而定——数值本身没有普适标准，关键是它由各题 ICC 在「刚够格」的 θ 上算出，有据可查。CAT 的选题规则是「当前 θ 附近信息量最大的题」，不是「总分相近的题」。

常见坑：把 CAT 理解成「按卷面总分从题库抽题」——CAT 全程不看卷面总分，看的是 θ 的当前估计与各题信息函数；这也正是它比纸笔测验省题又准的原因。

1. 第4讲作业的反馈（在第5讲课件开头）

作业原题：① 什么是测量效度？它与信度的关系怎样？② 假设需要编制一套小学高年级学生的阅读能力测验，试设计一个效度验证方案。

参考答案要点：

  • 关系题：课件明确判定「信度越高效度一般也会越高」是错的——信度管测得稳不稳，效度管测得准不准；测不稳固然测不准，但测得稳并不代表测的就是想要的东西。
  • 方案题（大家完成度还不错），三层设计：内容效度——专家评定，明确要测的阅读能力内容和范围（阅读速度 + 阅读理解 + 阅读记忆），按目的定纲目比例、逐题对比记录，再按内容覆盖率、题目难度与能力要求差异、题目数量与分数比例、题目形式与内容的适当性做总评价。
  • 结构效度——用因子分析结果与阅读能力的底层理论匹配；找已有的旧阅读能力测验求相关（相容效度）；找测量易混概念的测验求相关（区分效度）；发展差异验证（六年级学生阅读平均分应显著高于五年级）。
  • 效标关联效度（实证效度）——以语文考试中考察阅读能力部分的得分作效标，与测验结果求相关。

普遍丢分点：个别同学把信度和效度的关系弄错，答成「信度越高效度一般也会越高」。方案题三层都要点到：只写内容效度、不写效标关联效度，三层不全也会扣分。

1. P 越大，题目越难？

错。P 是通过率，P 越大越容易；越难 P 越接近 0。

2. CFA 需要像 EFA 那样先做因子旋转吗？

不需要。CFA 的结构由研究者事先指定，因子相关直接估计，无需旋转。

3. 一个因子配 3 个题目，模型恰好识别，自由度是多少？

df = 0。数据信息 3×4/2=6，待估参数 V、e1~e3、λ21、λ31 共 6 个，正好用完。

4. 高分组和低分组的通过率分别是 0.9 和 0.5，D 是多少，评价如何？

D = 0.9 − 0.5 = 0.40，按标准属于“很好”。

5. RMSEA = 0.06，这个模型拟合怎么样？

可接受（<.08），但不算良好（良好要 <.05）。
